# excavate —— 挖掘循环

目标：把土从一处搬到另一处。所有坐标都是**基座系地面点，单位米**（REP-103）——
来自 `get_terrain` 的料堆字段 `x_m` / `y_m`，不要自己估算坐标。

## 工作流

1. **读地形**：调用 `get_terrain`，得到料堆清单（名称 / 坐标 / 体积）。根据任务话术
   （"左边的土堆""白色桩标旁"）选出挖掘堆和倾倒点；若任务直接给了坐标则跳过此步。
2. **就位（可选）**：挖掘/倾倒点必须在当前可达半径内。若任务给的点离机身太远，
   先用 `navigate_relative`（或 `rotate_base`）把底盘挪到合理位置再开工。
3. **逐斗挖掘**：对每一斗调用
   `dig(dig_x_m, dig_y_m, dump_x_m, dump_y_m)`——一个调用就是一次完整循环
   （对准→下铲→收斗→摆转→卸料）。斗数按任务话术（"挖两斗""装满为止"）；
   若 `dig` 返回 `ok: false`，读 `error` 字段：超出可达半径 → 回到第 2 步走底盘；
   铲斗未卸料 → 先 `home` 再继续。
4. **复查地形**：每挖完一斗（或拿不准时）再调一次 `get_terrain`——挖掘会改变
   地形，之前的坐标观察已失效；据此决定继续挖、换堆、还是收工。
5. **收工**：全部完成后调用 `home` 回到安全收拢姿态。

## 注意

- **位置失效**：挖掘和行走都会让旧的料堆观察作废，凡是用旧坐标前先重新 `get_terrain`。
- 本技能的机器没有夹爪，`payload.held` 表示**铲斗里有料**；`dig` 的前置条件是斗空。
- [motion.base] 行走受每命令步长限制（底盘一次走不了太远），远距离分多次 `navigate_relative`。
